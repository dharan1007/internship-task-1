\section*{\color{ink}Appendix B \quad Tensor shapes and computational scale}
The configured input has shape $B\times3\times1536\times1536$. A
convolution with $16\times16$ kernel and stride 16 creates a $96\times96$
grid. Flattening gives 9,216 patch tokens; insertion of one learned
classification token gives a sequence length of 9,217. The hidden width
is 768 and the directional expansion width is 1,536.

\small
\begin{tabularx}{\linewidth}{@{}p{.27\linewidth}p{.27\linewidth}Y@{}}
\toprule
Stage & Tensor shape & Interpretation\\
\midrule
Input image & $B\times3\times1536\times1536$ & Full field is retained
by letterbox preprocessing\\
Patch embedding & $B\times9216\times768$ & One token per nonoverlapping
patch\\
Middle class token + positions & $B\times9217\times768$ & Positions are
learned and unique to this token sequence\\
Directional inner stream & $B\times9217\times1536$ & Forward and reverse
streams have separate convolution/SSM parameters\\
Selective state & $B\times1536\times16$ per direction & State dimension
is 16; the recurrent implementation does not need to retain a full
state tensor for every token at inference\\
Classifier output & $B\times5$ & Logits for ICDR grades 0 through 4\\
\bottomrule
\end{tabularx}
\normalsize

The depth is 24 blocks. The instantiated model has 103,760,645 trainable
parameters. A dense attention matrix over the same token sequence would
contain $L^2=84{,}953{,}089$ positions per head, before accounting for
queries, keys, values or gradients. The Vim design replaces this pairwise
attention operation with directional selective state updates. This count
explains the architecture choice; it does not prove superior accuracy or
whole-model speed for this repository.

\smallhead{Resolution choice}
The 1536-pixel input preserves substantially more fundus detail than a
small classification crop while requiring careful scan memory and runtime
qualification. The assignment and paper do not mandate this resolution.
The exact input geometry, patch size and token count are stored in
\code{configs/vim\_base\_eye.yaml} so a later run can be reconstructed.

\smallhead{Where memory can grow}
Patch-token activations scale with $BLD$ per block; directional state
computation also depends on expansion width and state size. Activation
checkpointing recomputes selected intermediates during backward. The
103.8-million parameter count alone does not determine GPU memory:
gradients, optimizer moments, decoded image batches and prefetch buffers
also matter. Qualification must measure a complete model step with the
chosen precision, batch and scan backend.

\section*{\color{ink}Appendix C \quad Selective-state derivation and paper map}
For each direction, the input-dependent projections generate $B_t$, $C_t$
and a positive step size $\Delta_t$. A learned log parameter defines a
negative diagonal state matrix $A=-\exp(A_{\log})$. The implemented
selective scan follows the Mamba input-drive convention:
\[
 \bar A_t=\exp(\Delta_t A),\qquad
 h_t=\bar A_t\odot h_{t-1}+\Delta_t B_t\odot x_t,
 \qquad y_t=\langle C_t,h_t\rangle+D\odot x_t.
\]
The forward stream reads tokens left to right. The reverse stream reads a
reversed copy and reverses its output back to original order. Both streams
have their own depthwise causal Conv1d, state projections, step projection,
$A_{\log}$ and skip vector. A shared projected gate $\operatorname{SiLU}(z)$
then modulates their \emph{sum}, followed by output projection and residual:
\[
 T_{\ell}=T_{\ell-1}
 +\operatorname{DropPath}\!\left(W_o[(y_{\rightarrow}+y_{\leftarrow})
 \odot\operatorname{SiLU}(z)]\right).
\]
The directional sum matches the paper's Algorithm 1. A code review on
4 November corrected an earlier factor of one-half in this expression.
The existing two-step GPU diagnostic was run before this correction and
must not be presented as qualification of the present source revision.

\smallhead{Reference, parallel and optional kernel paths}
The reference recurrence is intentionally direct and useful for numerical
comparison. The in-house parallel path composes affine transitions in
bounded chunks and implements backward propagation. An optional pinned
CUDA selective-scan dependency is a low-level efficiency path, never a
ready-made Vim model or a source of pretrained weights. Its benchmark is
scan-only; the corrected whole classifier has not been profiled with it.

\smallhead{Paper boundary}
The cited paper studies ImageNet and downstream dense prediction. This
project changes the task to five-grade retinal classification, initializes
weights randomly, uses 1536-pixel letterboxed inputs, and defines its own
training schedule. These task decisions and this implementation's timings
must not be confused with the paper's reported benchmark results
\cite{vim,mamba}.

\smallhead{Separate high-assurance candidate}

release lacks confirmed patient, site, device, adjudication and rights
metadata, so the candidate fails closed rather than inventing them.

licensable use: a strict interface cannot create missing clinical proof.

selection on held-out outcomes; it does not replace an independent
prospective validation study.

\section*{\color{ink}Appendix G \quad Training lifecycle and checkpoint identity}
The configured candidate uses AdamW, cross-entropy, $10^{-4}$ initial
learning rate, 0.05 weight decay, five warmup epochs and cosine decay.
Per-GPU batch is two, with four gradient-accumulation steps. For $G$
participating GPUs, the intended effective batch is $2\times4\times G$
real images per optimizer update, subject to end-of-epoch handling.
FP16 automatic mixed precision, gradient clipping at norm 1.0,
activation checkpointing, distributed sampling and a maximum drop-path
rate of 0.1 are configured. The declared ceiling is 300 epochs; it is a
project choice, not a requirement of the brief or the Vim paper.

The checkpoint stores model, optimizer, scheduler, scaler and random
number generator state with configuration, manifest and source identities.
An epoch-boundary pause writes resumable state without marking a full run
complete. Resume requires the same source, data split, configuration,
qualification and distributed world size. The best checkpoint is selected
by validation QWK alone.

An earlier BF16/parallel version completed two real-image optimizer steps

\section*{\color{ink}Appendix H \quad Evaluation definitions and outputs}
For comparable five-grade ICDR labels, the per-image record contains
source ID, true grade, predicted grade and five probabilities. The
confusion matrix has $C_{ij}=\#\{n:y_n=i,\hat y_n=j\}$. For each class,
precision is $TP/(TP+FP)$, recall is $TP/(TP+FN)$ and F1 is
$2PR/(P+R)$ under the code's explicit zero-denominator policy. Macro
values average the five class values; accuracy is
$\sum_i C_{ii}/\sum_{ij}C_{ij}$. QWK compares observed and expected
grade-pair frequencies with quadratic distance weights
$w_{ij}=(i-j)^2/(K-1)^2$. Undefined QWK is rejected.

\toprule

\midrule

precision/recall/F1, QWK, confusion matrix and referable proxy\\
Original Messidor & Its R0--R3 grades are not ICDR 0--4. Report the
predeclared binary proxy: true R2/R3 against predicted ICDR 2/3/4;
five-grade QWK against these labels would be invalid\\
Optional Messidor-2 & Five-grade metrics only after official images,
pairing metadata and independent adjudicated grades reconcile; disclose

\bottomrule
\end{tabularx}
\normalsize

The evaluation script verifies the selected checkpoint and source hashes,
runs inference, saves per-image rows, then computes metric JSON and plots.
The report generator recalculates results from saved rows before placing
confusion matrices, curves and real source image--prediction pairs in a
LaTeX report. This chain is implemented but has not yet produced a
classifier result. No number in this dossier is a DR accuracy, F1 or QWK
measurement for the model.

\smallhead{Required final artifact chain}
A completed run should create a validation-selected checkpoint and
training-complete record. The sealed evaluation then writes per-image
predictions, cohort metric JSON and confusion matrices. The report step
must compile the results TeX, place real image--prediction pairs only
when permitted, and tie displayed numbers to prediction rows. Training
and validation curves come from the epoch log; the external test cannot
contribute to those curves or checkpoint choice. Cohort denominators
must reflect explicit exclusions, including the 13 published original
Messidor duplicate removals.

invalid images, duplicate included image hashes, altered manifests,
